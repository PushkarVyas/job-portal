# Job Portal – MERN Stack Application

A full-stack **Job Portal web application** built using the **MERN stack**.  
This project allows users to search and apply for jobs, while recruiters can post jobs and manage applications.

The goal of this project was to gain **hands-on experience with real-world full-stack development**, including authentication, role-based access, state management, and modern UI practices.

---

## 🚀 Features

### 👤 Authentication
- User signup & login (JWT-based authentication)
- Role-based access (Student / Recruiter)
- Secure routes using middleware

### 🎓 Student Features
- Browse and search jobs
- View job details
- Apply for jobs
- Upload resume (PDF)
- View application status

### 🏢 Recruiter Features
- Register company
- Post jobs
- View posted jobs
- View applicants for each job
- Accept / Reject applications

### 🛠 Admin / Recruiter Dashboard
- Manage companies
- Manage job postings
- View applicants in tabular format

---

## 🧰 Tech Stack

### Frontend
- React.js
- Redux Toolkit (state management)
- React Router
- shadcn/ui
- Tailwind CSS
- Axios

### Backend
- Node.js
- Express.js
- MongoDB & Mongoose
- JWT Authentication
- Multer (file uploads)
- Cloudinary (resume & profile image storage)
